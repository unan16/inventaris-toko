# Aplikasi Inventaris Toko

Aplikasi manajemen stok produk berbasis Laravel 12 + Filament v3.

## Fitur Utama
- Manajemen Kategori Produk
- Manajemen Produk (CRUD)
- Manajemen Supplier
- Pencatatan Riwayat Stok
- Relasi antar tabel: Category, Product, Supplier, StockLog
- Proteksi dasar dan pengujian keamanan

## Tools & Teknologi
- Laravel 12
- Filament v3
- PHP 8+
- MySQL (XAMPP)
- GitHub
